# Student Expense Tracker

A command-line Student Expense Tracker developed as a Python Essentials course project.
## Overview

The Student Expense Tracker is a Python-based command-line application that helps students record, view, search, and analyze their daily expenses. 
## Problem Statement

Students often make small daily expenses but may not maintain a proper record of their spending. This project provides a simple command-line solution for recording and analyzing expenses.
## Objectives

- Record daily expenses.
- View stored expenses.
- Search expenses by category.
- Calculate total spending.
- Generate category-wise spending summaries.
- Apply essential Python programming concepts.

- ## Features

- Add a new expense
- View all expenses
- Search expenses by category
- Calculate total expenses
- Show category-wise spending
- ## How It Works

1. User enters expense details.
2. Expense is stored in the program.
3. User can view all recorded expenses.
4. User can search expenses by category.
5. The program calculates total spending.
6. Category-wise spending is displayed.
